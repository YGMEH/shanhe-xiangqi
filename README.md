# 山河弈阵

一个把中国象棋放进起伏山地场景里的 3D 对弈游戏。棋盘不是平面贴图，而是嵌入
真实地形的九列十行；楚河下切为动态水面，中央、左右石桥成为跨河通道。七类棋子
均有独立程序化模型、待机动作和攻击动作，火炮会发射抛物线炮弹。

## 当前内容

- 完整象棋规则：将帅、士、象、马、车、炮、兵，包含蹩马腿、将帅照面、将军与将死
- 本作地形规则：纵向跨河必须经过三座石桥之一；兵卒过河后可横走
- 人机对弈：三档棋力，含局面评估、着法排序与多层搜索
- 双人演武：同一设备轮流操作
- 三维战场：起伏地形、动态楚河、实体桥面、军旗、山谷环境与昼夜氛围
- 七类程序化模型：将帅、军师、战象、骑兵、战车、火炮、长矛兵
- 动作表现：各自待机动作、攻击动作、行军动画、炮弹轨迹、烟尘与命中特效
- 完整对局循环：选子、合法落点、走子、吃子、将军、悔棋、重开、胜负结算
- 音频系统：环境风声、行军、重击、炮击、将军与胜负音效
- 响应式界面：桌面与移动端都可操作，支持键盘快捷键
- 画面品质选项：自动适配、精细渲染、性能优先

## 操作

- 拖动鼠标或手指：旋转视角
- 滚轮或双指：缩放
- 点击棋子：显示可走位置
- 点击落点：行棋
- `U`：悔棋
- `R`：重开
- `Space`：切换视角
- `Esc`：取消选择或关闭规则

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:4173`。

生产构建：

```bash
npm run build
npm run preview
```

规则测试：

```bash
npm test
```

发布前检查（根绝对路径、密钥、本机路径）：

```bash
npm run check:public
```

## 在线版本

推送到 `main` 分支后，GitHub Actions 会自动测试、构建并发布到 GitHub Pages。
项目通过相对路径引用资源，因此可以直接部署在仓库子路径下。

## 目录

```text
src/
  game/             规则、棋盘、AI、对局状态机
  render/           Three.js 场景、地形、棋子、材质、特效
  audio/            程序化音频
  ui/               界面状态与文本
tests/              规则单元测试
docs/               美术资产替换说明
public/assets/      可替换的 PBR 材质
```
